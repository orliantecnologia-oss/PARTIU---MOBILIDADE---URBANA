# 🏛️ UniVans TOS — Arquitetura Final de Produção (V3.4)

## 1. Visão Geral

O UniVans TOS é o Sistema Operacional de Transporte projetado para operar com isolamento rigoroso por cooperativa (Multi-Tenant), tolerância total a apagão de internet (Offline-First), integridade contábil matemática (Double-Entry Bookkeeping) e alta precisão geoespacial (PostGIS).

## 2. Camadas da Arquitetura

1. **Camada de Apresentação:** React 19 + TanStack Start (SSR Nitro) + Tailwind CSS + Mapbox GL JS WebGL.
2. **Camada de Aplicação & Domínio:** Máquinas de Estado Formais com guards estritos, Motor Global de Idempotência e Outbox/Inbox Pattern.
3. **Camada de Persistência & Spatial:** PostgreSQL 15+ com PostGIS e Row Level Security (RLS) mandatória em todas as 22 tabelas mestre e suporte.
4. **Camada de Segurança:** Gestão e rotação de chaves Ed25519 (coexistência N e N-1), Rate Limiting por endpoint e mascaramento automático de logs.
