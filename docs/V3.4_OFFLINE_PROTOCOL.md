# ⛓️ UniVans TOS — Protocolo de Bilhetagem Offline & Fila Durável (V3.4)

## 1. Arquitetura da Fila Local

- **Encadeamento Criptográfico:** Cada evento contém `event_hash`, `previous_event_hash` e contador monotônico sequencial.
- **Detecção de Sequence Gaps:** Identifica se eventos intermediários foram suprimidos (ex: [101, 102, 103, 105] -> detecta 104 faltando).
- **Detecção de Counter Rollback:** Rejeita tentativas de reinicialização fraudulenta de sequência local.
- **Protocolo ACK:** O evento só é marcado como sincronizado após confirmação transacional do backend.
